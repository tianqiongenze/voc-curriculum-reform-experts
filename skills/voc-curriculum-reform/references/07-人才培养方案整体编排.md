# 07 人才培养方案整体编排

> 人培方案不是一个文件，是**一所学校对某个专业的公开承诺**：承诺培养什么人、开什么课、谁来教、怎么保证质量。承诺写得漂亮但兑现不了，评估时会被逐条追问。

---

## 一、三个层次，别搞混

| 层次 | 是什么 | 谁定 | 能不能改 |
|---|---|---|---|
| 国家专业教学标准 | 底线：专业名称代码、培养目标框架、核心课程、师资与条件要求 | 国家 | 不能改，只能高于 |
| 省级/行业要求 | 区域补充：区域产业对接、证书要求、学时区间 | 省级教育行政部门/行业 | 在框架内落实 |
| 院校方案 | 落地：本校的培养目标、课程体系、进程、保障 | 学校 | 自主设计，但不得低于前两层 |

**判据**：人培方案里每一条"特色"，都要能回答"国标底线在哪、我们高在哪"。

---

## 二、十章结构（逐章要点）

### 一、专业名称及代码
与现行专业目录完全一致；有方向班的在方案内单列说明，不擅自改专业名。

### 二、入学要求
普通高中毕业生 / 中等职业学校毕业生或同等学力。中高职贯通、五年一贯制的要单列口径。

### 三、修业年限
三年制为主。弹性学制的要写明"最长修业年限"与"学分制管理"办法。

### 四、职业面向

| 项 | 写法 | 常见错误 |
|---|---|---|
| 所属专业大类/专业类 | 按目录填 | 填成学院名 |
| 对应行业 | 2-4 个，用国民经济行业分类名称 | 写成"制造业"这种过粗口径 |
| 主要职业类别 | 按职业分类大典名称 | 自创岗位名 |
| 主要岗位群/技术领域 | 4-6 个岗位群，分初/中/高 | 罗列 20 个岗位，无层次 |
| 职业证书 | 1+X 或行业证书，写等级 | 写"相关证书" |

### 五、培养目标与培养规格

**培养目标**（1 段，3-5 句）：毕业 3-5 年能成为什么样的人、在什么岗位、能做什么事、具备什么职业品格。
**培养规格**（三块，逐条可测）：
- 素质：思想政治、职业素养、身心素质（写行为，不写口号）
- 知识：本专业必需的知识单元（对应课程模块）
- 能力：专业技术能力 + 方法能力 + 社会能力 + 发展能力（对应 PGSD 四维）

**目标 vs 规格 的区别**（最常混写）：

| | 培养目标 | 培养规格 |
|---|---|---|
| 时间尺度 | 毕业后 3-5 年 | 毕业时 |
| 粒度 | 一段话，方向性 | 逐条，可测 |
| 检验方式 | 就业质量、职业发展 | 课程达成度、毕业审核 |

### 六、课程设置
四层结构 + 学时占比：

| 类别 | 内容 | 学时特征 | 设计要点 |
|---|---|---|---|
| 公共基础课 | 思政、体育、外语、数学、信息技术、创新创业、劳动教育 | 不少于总学时 25%（常见底线） | 与专业结合上（如专业英语、工程数学） |
| 专业基础课 | 电工电子、程序设计、网络基础、安全防护 | 单门 8-64h | **独立设课**，避免与 LF 重复计学时 |
| 专业核心课（含 LF） | 对应工作领域的 LF，加国标核心课程 | 单门 32-160h | 六步情境化，能力等级 L1-L4 递进 |
| 专业拓展课 | 新技术、交叉方向、证书课 | 16-32h | 支撑 L4 与迁移能力 |
| 实习实训 | 认知实习、跟岗实习、顶岗实习、毕业设计 | 按周计 | 与 LF6 综合项目衔接，不重叠 |

**国标核心课程必须逐门落位**，且做"国标名称 ↔ 校本名称"映射，评审时按国标名可查。

### 七、学时安排
必算五组数：总学时、各类课程学时与占比、周学时、教学周数、实践性学时占比。
常见底线参数（以现行文件与院校规定为准）：三年制总学时一般不低于 2500；公共基础课 ≥25%；选修 ≥10%；实践性教学 ≥50%。

### 八、教学进程总体安排
学期 × 课程矩阵，列：课程名称、课程类别、学分、学时（理论/实践）、周学时、开课学期、考核方式、备注。
**硬要求**：与课程体系表（Table5）逐格一致；先修关系无环；重课不扎堆；最后一学期留出顶岗与补修窗口。

### 九、实施保障
| 块 | 必写指标 |
|---|---|
| 师资队伍 | 生师比、双师比例、企业兼职教师课时占比、专业带头人条件 |
| 教学设施 | 实训室数量、工位数、生均台套、设备总值 |
| 教学资源 | 教材（含活页）、数字资源、平台账号 |
| 教学方法 | 六步行动导向、分层教学、AI 三层梯度 |
| 学习评价 | 过程性+终结性比例、Rubric、第三方评价 |
| 质量管理 | 诊改机制、数据平台、督导与反馈闭环 |

### 十、毕业要求
学分要求 + 证书要求 + 能力要求（对应到能力原子）+ 素质要求（操行、体测）。
**三级对齐检验**：每条培养规格 → 至少 1 门课程支撑 → 至少 1 种评价证明。

### 附录
**学校标准样文（教育部模板）没有附录章。** 课程与任务对应表、能力原子清单、学时双口径明细等矩阵类内容放材料包的 Table 系列文件，人培方案正文只引用（"见 Table5 V1.0 §x"），不内嵌。方案变更审批表、企业参与证明清单由院校教务流程另行存档，不进方案。

| 步 | 动作 | 产出 | 责任人 |
|:---:|---|---|---|
| 1 | 政策与标准研读 | 底线清单（国标/省标/校规） | 专业负责人 |

## 四、学时学分闭合（四级校验）

```
模块学时之和 = 课程学时
课程学时之和 = 学期学时
学期学时之和 = 总学时
总学分 = 总学时 / 换算系数（常见 16 或 18，全表统一）

开设口径 = 计划开设的全部学时（排课用）
实修口径 = 学生必须修完的学时（毕业审核用）
差额 = 开设 − 实修，必须有书面说明（如选修未修、学分互认）
选修比例 = 选修学时 / 总学时 ≥ 10%
实践比例 = 实践性学时 / 总学时 ≥ 50%
```

**改一处，四处重算**。每次改版出一张"变动影响表"。

## 五、版本治理（从多轮修订里学到的）

| 常见升级 | 内容 | 教训 |
|---|---|---|
| 能力模型升级 | CKQ（能力-知识-素质二维）→ PGSD-KSA（四层递进 × 三维融合） | 模型升级必须同步改矩阵与课标，否则两套语言 |
| 学时从模糊到闭合 | 补全每门课学时、做双口径 | 学时不清的方案无法排课，等于没写 |
| 调研从二手到一手 | 增加企业访谈、样本量与结论对应 | 二手数据写不出"岗位真实约束" |
| 调研方法升级 | AI 辅助调研（访前梳理技术栈、访中记录标注、访后结构化分析） | 提高效率，但结论仍需企业确认 |

**版本说明模板**：

```
V{x}（日期）：改了什么 / 为什么改 / 影响哪些表 / 需谁确认
```

## 六、评审视角的 12 个追问（提前准备答案）

1. 你们专业对应产业链哪个环节？凭什么这么定位？
2. 四大岗位群是怎么得出来的？访谈了多少家企业？
3. 12 项任务的 L2-L3 占多少？为什么是这个区间？
4. 国标核心课程全覆盖了吗？哪门没覆盖，谁补？
5. 总学时多少？选修比例多少？实践比例多少？
6. 学时加得平吗？开设口径和实修口径差在哪？
7. 每门 LF 对应哪个工作领域？学时怎么分的？
8. 学生毕业时能达到什么水平？用什么证明？
9. 双师比例多少？企业教师上多少课时？
10. 实训工位多少？32 人怎么排？
11. 这门新课谁上？教师从哪来、怎么培养？
12. 方案怎么迭代？上一版改了什么、为什么改？

## 七、常见退回原因

| 退回意见 | 根因 | 修法 |
|---|---|---|
| 培养目标与规格混写 | 概念不清 | 目标写"3-5 年后"，规格写"毕业时"，分表 |
| 规格不可测 | 用形容词 | 按行为动词改写，绑定课程与评价 |
| 课程与国标不符 | 没做映射 | 建国标名称映射表，逐门落位 |
| 学时加不平 | 改动不回填 | 四级校验，出变动影响表 |
| 实践比例不足 | 理论课堆太多 | 调模块结构，增加实训学时 |
| 选修比例不足 | 全是必修 | 设专业拓展课模块，列选修包 |
| 保障写成口号 | 无指标 | 每块给 2-3 个数字指标 |
| 进程表与体系表不一致 | 两套数据 | 以 Table5 为唯一数据源，反向生成进程表 |
| 课标缺失 | 只做方案不做配套 | 同步产出课标，至少核心课全覆盖 |
| 无企业参与证据 | 校企合作停留在口头上 | 补协议、企业专家名单、参与记录 |

### 9.4 抉择规则（没有数据时怎么填，不许编造）

1. **人名**：专业负责人／企业负责人／学院负责人未知 → 填"（待定）"，不编造
2. **职业代码**：主要职业类别代码以《职业分类大典》核定为准 → 名称＋括注，不编 9 位码
3. **课程代码**：教务系统代码未分配 → 用校本编号 C01—C43 并在表头注明"正式代码以教务系统分配为准"
4. **企业名单**：合作企业未知 → 写类别＋"清单与合作协议另行备案"，不编企业名
5. **线上线下学时拆分**：无数据 → 进程表只列理论／实践两列，不拆
6. **周学时口径**：单学期课程＝学时÷16；跨学期课程（体育、英语）按学期分布列周学时、学分按学期拆分；集中实习（认知实习）不计入周学时；S6 按 20 周折算，岗位实习与毕业设计 sequential 分周段标注
