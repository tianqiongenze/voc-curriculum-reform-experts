# 11 院校材料体例与格式规范（House Style）

> 一套材料能不能被院校直接用，一半看内容，一半看**长得像不像本校的东西**。教务处的老师不读长文，他们对照上一版找差异；评审专家也先看体例是否规范，再看内容。
>
> 本规范由院校既有材料反推而来。**产出必须与之同构**，否则一律退回重排。

---

## 一、通用前置块（六表、课标、教案、人培都要有）

### 1.1 标题行

```
# {专业名称}专业（{专业代码}）——{表名}（V{版本}·{版本特征}版）
```

版本特征用短语点明这一版改了什么，如"专业基础课独立设课版""四层递进模型·12任务对齐版"。**不许只写 V70 不写特征。**

### 1.2 编制信息块（六表必备，顺序固定）

```
编制基础：Table1 V{xx}（典型职业活动与工作任务表·{n}任务）+ Table2 V{xx}（PGSD-KSA能力融合矩阵·{n}行）+ Table5 V{xx}（课程体系与教学进程表·{h}h/{cr}cr）
编制对象：{学校}{专业}{年级}学生（{毕业年}年毕业）
编制依据：{政策文件}、赵志群行动导向教改理论、德国双元制标准、BAG-GY七步法
数据来源：{n}个岗位JD（列举）+ {n}位企业实践专家访谈 + {n}家企业调研报告
等级分布：L1×{n}({p}%) → L2×{n}({p}%) → L3×{n}({p}%) → L4×{n}({p}%) = {n}个任务
方法论底座：赵志群BAG典型任务开发方法论 + PGSD-KSA能力分析模型 + {本版模型名}
```

### 1.3 核心发现融入块（可选，有调研就写）

```
{n}项核心发现融入：①{发现}→{落在哪} ②{发现}→{落在哪} …
```

### 1.4 AIGC 标识（合规项，**不得编造**）

院校既有文件头部有一段 YAML：

```yaml
---
AIGC:
    Label: "1"
    ContentProducer: {备案编号}
    ProduceID: {生成记录ID}
    ...
---
```

**红线**：`ContentProducer`、`ProduceID` 是备案与追溯编号，**新产出不得填写、不得沿用他文件的编号**。处理方式二选一：
- 删掉整段（校内使用）；
- 保留结构，值写 `【待按《人工智能生成合成内容标识办法》填写】`（对外发布前由院校填）。

## 二、Table1–Table6 各自体例

### Table1 典型职业活动与工作任务表（13 列，固定顺序）

`序号｜工作领域｜典型工作任务｜等级｜工作过程/步骤拆解｜工作组织形式｜关联核心技能｜岗位设置情况｜关联JD岗位与任职资格｜转化课程建议｜德国双元制对应技能｜对应程度｜备注`

- **按工作领域分节**，每节一张表，不混排。
- 步骤列用 `<br>` 或编号 1.2.3，每步"动作〔依据〕→输出"。
- 岗位设置五要素：岗位名称／所在部门／工作场所／常用设施设备／跨部门协作。
- 对应程度：🔴 高度／🟡 中度／⚪ 弱。
- 表后必须有：等级分布校验表 + 课程覆盖率校验 + 修正点对照表 + 版本历史。

### Table2 PGSD-KSA 能力融合矩阵

- 头部写"维度规则：每项 BAG 拆 4 行（P/G/S/D），{n}×4={n} 行"。
- 列：`序号｜任务名称｜任务等级｜维度｜知识(K)｜技能(S)｜素养(A)｜重要程度｜对应岗位群｜德国双元制映射`
- 重要程度用 ★☆☆／★★☆／★★★。
- 每格必须含"知识来源"（哪门课、哪个模块、多少学时）。

### Table3 职业发展路径及关键行为条件表

- 先写 **Dreyfus 等级对照**（L1 入门 0-0.5 年 / L2 初级 0.5-1.5 年 / L3 中级 1.5-3 年 / L4 高级 3-5 年，L5 高职不涉及）。
- 按**职业发展路径**分节（路径一、路径二…），每节一张表。
- 列：`序号｜岗位名称｜岗位层级｜工作领域｜典型工作任务｜晋升周期｜关键行为条件（硬技能/关键行为/职业技能等级证书/成果指标）｜对应课程支撑层级｜备注`

### Table4 岗位职业能力可视化图谱

- 按"序号 N."分节，每节一个岗位。
- 每岗位写：岗位画像 → 能力单元（分层级）→ 对应任务 → 对应课程 → 可视化关系（用缩进树或 ASCII 图）。
- 头部必须写"等级分布"与"LF 学时"。

### Table5 课程体系与教学进程表

- 头部块换成：`适用级次／学制／总学时／总学分／实践占比`，再写"V{n} 版本核心突破"（3-6 条）。
- 正文顺序：①版本改进逻辑（诊断→解决）②课程体系总览（四层结构表）③分学期进程表（课程×学期）④学时学分账 ⑤覆盖率与国标校验。
- 每个数字必须可加总。

### Table6 岗位职业能力综合矩阵表

- "编制说明"六条：编制基础／编制对象／方法论底座／组织方式／数据量／课程体系校准，再加"学情背景"与"学情分层说明"。
- 按四大路径分组，每组一张表，列含 P/G/S/D-K/S/A 完整数据 + 课程支撑 + 评价方式。

## 三、课程标准（11 章）

章节编号用带圈数字，顺序不可变：

```
① 课程基本信息
② 课程性质与设计思路（②.1 学习领域定位 / ②.2 BAG→学习领域转化路径 四条原则 / ②.3 衔接关系）
③ 国家教学标准对应分析（③.1 定位 / ③.2 三要素覆盖 ✅⚠ / ③.3 学时闭环 / ③.4 差异分析 / ③.5 覆盖度结论）
④ 课程目标 PGSD-KSA（④.1 总体 / ④.2 分解·绑定原子ID / ④.3 ABCD 分层）
⑤ 工作与学习内容五要素（对象／工具材料资料／方法与劳动组织／要求与质量标准）
⑥ 学习情境划分（⑥.1 总览 / ⑥.2 六步学时校验 / ⑥.3 各情境详表）
⑦ 教学实施建议（⑦.1 六步要点 / ⑦.2 教师角色矩阵 / ⑦.3 AI 三层梯度 / ⑦.4 组织建议）
⑧ 考核评价（⑧.1 权重 / ⑧.2 Rubric 四维四档 / ⑧.3 COMET / ⑧.4 一票否决）
⑨ 教学资源与条件（硬件／软件／师资／教材／数字资源／活页工作页）
⑩ 安全与伦理红线（⑩.1 总览 / ⑩.2 情境细则 / ⑩.3 教育实施）
附录 A 规范清单 / 附录 B 交付物模板 / 附录 C AI 工具三层清单 / 附录 D Rubric 阈值与 COMET
```

**无官方教学标准时**，③ 改为"课程池对标与相近专业去重分析"，并在 ③.1 置顶加粗声明"不得表述为依据/符合国家教学标准"。

## 四、6×4 分层教案

- 版式：GitBook 风（左目录 + 右正文 + 顶部版本条），蓝/浅色系。
- 顶部条写：`6×4分层教案 · V{xx} · {配色} · {承载BAG} · 生成于 {日期} · D类{n}条`。
- 每个情境一节，节内固定四块：**六步×四层网格表 / 时间分配 / 交付物 / D 类红线**。
- 网格表列头固定：`六步｜A 领跑｜B 主力｜C 跟进｜D 兜底`。

## 五、人才培养方案（十章·学校标准体例）

**格式基准：院校《2026级智能机器人技术人才培养方案8.30（最新版）.docx》（教育部高职模板）。** 章名、表号、列序、编号体系向样文看齐，详细硬规范见 `07-人才培养方案整体编排.md` 第九节。

```
封面块：专业名称／专业代码／专业大类／学制／制订日期／专业负责人（待定）／企业负责人（待定）／学院负责人（待定）

一 专业名称及代码（含一句编制口径说明：标准未发布的写降级路径）
二 入学要求
三 修业年限（三年＋总学时总学分）
四 职业面向与岗位分析
  （一）职业面向 → 表1（A 专业大类／B 专业类／C 对应行业／D 主要职业类别／E 主要岗位类别／F 证书举例）
  （二）主要工作岗位分析 → 表2（序号／岗位名称／初始岗位0—1年／发展岗位1—3年／岗位能力要求 P·G·S·D 四维）
  （三）主要证书 → 表3（证书类型／证书名称／颁证单位／建议等级）
五 培养目标与培养规格
  （一）培养目标（一段式，末句带"目标能力区间：L1—L3"）
  （二）培养规格（1.A素质 2.K知识 3.S能力，条款式 (1)(2)(3)…，不挂四列表）
六 课程设置及要求
  （一）公共基础课程 → 表4（序号／课程名称／主要教学内容和要求／总学时）
  （二）专业（技能）课程 → 表5 专业基础／表6 专业核心（多"典型工作任务（学习情境）"列）／表7 专业拓展（文末"必须修满X学分"）
  （三）实践性教学环节 → 表8
  （四）学时安排 → 表9 学分学时分配表 ＋ 表10 证书学分转换表 ＋ 一段总量文字
  （五）课程思政（一段式）
七 教学进程总体安排 → 表11（课程类别／性质／名称／课程代码／开课单位／总学分／总学时／理论／实践／考核方式／六学期周学时／备注＋合计行）
八 实施保障 →（一）师资队伍（二）教学设施（三）教学资源（四）教学方法（五）学习评价（六）质量管理
九 毕业要求（学分＋证书＋能力＋素质，一段式）
十 持续发展建议（途径＋升本＋对应本科专业）
```

**编号体系**：章用中文数字"一、二…"；节用"（一）（二）"；条用"**1. A 素质要求**＋(1)(2)"；表号连续（表1—表11）。

**封面与目录（人培专有，样文实测 2026-10-25）**：
- **封面页**（独占一页，页脚"— 页码 —"）：①校名行（居中，方正黑体_GBK 22pt；院校可替换为校徽图片）②空两行 ③标题两行（居中，方正小标宋_GBK 26pt；≥18 字时在"专业"后手动换行，禁止自动断行出单字行）④"（适用于20XX级）"（居中，楷体 16pt）⑤空三行 ⑥封面信息表：2 列 2667/4815 twips 居中固定布局，8 行（专业名称／专业代码／专业大类／学制／专业负责人／企业负责人／学院负责人／制订日期），标签右对齐、值居中、每格仅下边线（single sz4），标签方正黑体_GBK 15pt、值方正仿宋_GBK 15pt；未知值填"（待定）"⑦分节符（纵版）
- **目录页**（独占一页）："目　录"居中（方正小标宋_GBK 18pt）→ **真 TOC 域**（`TOC \o "1-3" \h \z \u`，缓存结果即点线条目：右制表位 8306 twips＋点线前导，章级方正黑体_GBK 15pt、节级方正楷体_GBK 15pt，段后 60 行距 240 保证一页）→ 分页符
- **正文首页**：标题重复（居中 22pt）＋"（适用于20XX级）"（居中，方正仿宋_GBK 16pt），**用普通段落不用 Heading 样式**（不进目录）；章标题才是 Heading1、节标题 Heading2——保证用户按 F9 更新目录域后层级不错
- **页码口径**：目录页码＝PDF 物理页−（封面页数＋目录页数），从正文第 1 页起算为 1；目录可能占多页，**动态测定正文起始页（跳过含点线的页），不写死偏移**
- **实现**：`scripts/批量转Word与PDF.py` 的 `rebuild_rp_cover_toc()`＋`extract_toc_pages()`＋`fill_toc_pages()`（两遍法：先转 PDF 提取各章真实页码，回填目录域缓存，再重转）；**页脚部件只给人培注入**，课标等文件不设页码（院校惯例）

**删除清单（样文没有的，一律不进正文）**：【依据说明】大块／LF 一览表／双口径账表／L4 论证／附录章／版本历史表／四列规格挂接表。矩阵类内容放 Table 系列，正文只写"见 Table5 V1.0 §x"。

**抉择规则（无数据不编造）**：人名填"（待定）"；职业代码写名称＋"以大典核定为准"；课程代码用校本编号 C01—C43 并注明"以教务系统分配为准"；企业名单写"另行备案"；无线上线下数据就不拆列；集中实习不计周学时；S6 按 20 周折算、岗位实习与毕设 sequential 标周段。
