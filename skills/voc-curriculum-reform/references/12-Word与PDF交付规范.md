# 12｜Word 与 PDF 交付规范（院校体例）

> 适用：把 md/html 产出转为院校同款 Word（.docx）与 PDF。
> 版式基准：**解包院校既有 docx 实测**（2026-10-24，样本：Table1 V80、LF4 课标正式版、人培 V2.7）。
> 本文件是"照已有文件格式办事"的唯一依据；与 11 号（体例规范）配合使用——11 管内容结构，12 管落盘格式。

## 二、转换链（唯一合法路径）

```
.md ──pandoc + 院校Word参考模板──▶ .docx ──后处理──▶ .docx ──LibreOffice──▶ .pdf
.html ─────────同上────────▶ .docx ──后处理──▶ .docx ──LibreOffice──▶ .pdf
```

工具：`pandoc ≥3`、`LibreOffice（soffice）`。脚本在
`skills/voc-curriculum-reform/scripts/`：
- `构建院校Word参考模板.py` —— 由 pandoc 默认 reference.docx 生成院校模板
- `批量转Word与PDF.py` —— 一键转全目录，含后处理

**命名**：与源文件同名同目录，只换扩展名（院校目录惯例：`LF4_….md.docx` 与 `.md` 并存）。

## 三、后处理五项（pandoc 做不到的，必须补）

| # | 问题 | 处置 |
|---|---|---|
| 1 | 引用块落到 pandoc 的 "Block Text" | 改 pStyle 为院校自定义 **Blockquote**（楷体灰字）。⚠ pandoc 输出是 `<w:pStyle w:val="BlockText" />`，斜杠前有空格，精确匹配会漏 |
| 2 | `---` 被 pandoc 3.x 画成 VML `<v:rect>` | 替换为 HorizontalRule 样式段 + CCCCCC 底边框 |
| 3 | 表头不加粗、不跨页重复 | 首行所有 run 加 `<w:b/>`；首行 trPr 插 `<w:tblHeader/>`（**院校原文件未设此项，属改进项**，长表跨页必须留表头） |
| 4 | 宽表（≥9列）在 A4 纵向挤成竖条 | **横版节包裹**：表前插纵版 sectPr 段、表后插横版 sectPr 段；列宽等比撑满所在节文本宽（纵8312／横13958 twips） |
| 5 | 表格字号一律 11pt | 宽表降字号：≥13列 8pt，9–12列 9pt |

**横版判定**：院校六表中 Table1(13列)/Table2(10)/Table3(9)/Table5(11-12)/Table6(11) 及人培进程表均为宽表，**必须横版**。院校原文件把这些表硬塞在纵向（单元格只有短关键词）；我们的表装了完整工作过程，密度高数倍，不横版不可读。

## 三·补、人培方案的封面与目录（WPS 兼容，样文实测）

**问题**：pandoc 直出的人培封面是"H1 蓝灰标题＋粗体字段段"，目录是"纯文本行"——WPS 里无点线、无页码、无封面表，正是"混乱"的来源。学校标准是：居中大标题封面＋8 行信息表＋真 TOC 域。

**转换器自动完成**（`rebuild_rp_cover_toc`＋`extract_toc_pages`＋`fill_toc_pages`，两遍法）：
1. 删掉 md 直出的封面/目录区，重建为：校名行（黑体 22pt 居中）→ 标题两行（小标宋 26pt，≥18 字在"专业"后手动换行）→"（适用于20XX级）"（楷体 16pt）→ 封面信息表（2 列 2667/4815 居中，每格下边线，标签黑体右对齐/值仿宋居中 15pt）→ 分节符
2. 目录页："目　录"（小标宋 18pt 居中）＋**真 TOC 域**（`TOC \o "1-3" \h \z \u`），缓存结果为点线条目（右制表位 8306＋dot 前导，章级黑体、节级楷体、15pt，段后 60 保证一页）→ 分页符
3. 正文首页重复大标题（**普通段落**），同时把正文 H2→Heading1、H3→Heading2（用户按 F9 更新域后层级仍正确）
4. 页脚"— 页码 —"（PAGE 域）**只给人培注入**——课标等文件按院校惯例不设页码；注意：给无 footer 部件的文件挂 footerReference 会导致 LibreOffice 拒绝加载（曾因此 8 个文件转换失败）
5. 页码两遍回填：先转 PDF（目录页码占位）→ 动态测定正文起始页（跳过封面与含点线的目录页，**目录可能多页，不写死偏移**）→ 回填缓存 → 重转 PDF

**验收**：封面一页、目录一页（26 条不溢出）、页码抽查对应（正文第 1 页＝页码 1）、WPS 打开即显示点线页码且 F9 可更新。

## 四、质量验收（每次转换后必查）

1. **字体落地**：正文宋体、标题蓝灰加粗、引用块楷体——抽 1 页渲染看图，不只看文件生成成功
2. **混合朝向**：`pdfinfo -f 1 -l N` 逐页核对，宽表页应为 841.89×595.304
3. **表格满宽**：竖边框应落在文本区边界（纵 124→703px @100dpi）。**用像素/bbox 实测，不目测**（目测会把满宽误判成 60%）
4. **页数合理**：课标 20–50 页、六表 10–35 页、教案 10–15 页；异常膨胀 = 表格被挤窄
5. **内容零丢失**：docx 与 md 逐表计数一致（表格数、行数）
6. **docx 可再编辑**：Word/WPS 能打开、样式面板可见 Heading1-4/Blockquote/HorizontalRule

## 五、已知边界（不许吹成万能）

1. **HTML→Word 丢交互**：CSS/`:target`/`details` 不转换，只保内容与表格。互动版以 HTML 原件为准，Word/PDF 是内容保底版
2. **emoji 渲染依赖系统字体**：🔴🟡⚪ 在 macOS/LibreOffice 下正常，Windows 无彩色 emoji 字体时降为单色——**正式文件尽量不用 emoji 表意**
3. **同名冲突**：`X.md` 与 `X.html` 会生成同名 `X.docx`。**权威源是 md**，脚本按文件名排序后者覆盖前者；html 互动版不应与 md 重名到只差扩展名
4. **AIGC 标识段不预置编号**：Word/PDF 里同样只写注释行，由院校填 `ContentProducer/ProduceID`
5. **不生成目录域**：pandoc 不出 Word 自带 TOC 域；如需可编辑目录，在 Word 里"引用→目录"一键生成

## 六、给院校交件时的自检表

- [ ] docx 与 pdf 同名同目录，数量与源文件一致
- [ ] 宽表全部横版、表头跨页重复
- [ ] 无 BlockText/Compact 残留 pStyle（样式面板抽查）
- [ ] 无 VML 分隔线残留（搜索 `v:rect`）
- [ ] AIGC 段未填编号
- [ ] 字体为宋体/楷体（不是 Calibri/等线）
- [ ] 抽 3 页渲染检查：标题色值、表格边框、引用块楷体
