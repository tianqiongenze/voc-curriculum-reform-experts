# 13 互动学习资源开发规范（学生模块＋教师授课包）

> 适用：把每个学习情境（LF-Q）做成"老师直接授课、学生直接自学"的两件套。
> 产出：**学生互动学习模块**（单文件 HTML，有交互）＋**教师授课包**（单文件 HTML，零 JS）。
> 金标准：`LF1_数据采集与标注_6×4分层教案_正式版.html`（教师包）、`LF1-Q2_标注规范执行_学生互动学习模块_正式版.html`（学生模块）。

---

## 一、两件套的分工（别做混）

| 件 | 使用者 | 打开场景 | 形态 |
|---|---|---|---|
| 学生互动学习模块 | 学生 | 课前预习／课后自学／仿真实训／自我检测 | 有 JS 交互：翻卡、闯关、模拟器、测验 |
| 教师授课包 | 教师 | 备课／上课投屏／印发 | 零 JS GitBook 风：网格表、工单、量规、案例卡 |

**同一个情境的两件套数据必须一致**（六步学时、原子、红线、交付物）——以课标为唯一源。

## 二、学生互动模块：固定七段（缺一段即退回）

```
① 顶部条：模块名｜情境｜学时｜达标线 80%｜生成日期｜"教学样例数据"声明
② 情境引入：场景叙事（用课标情境描述原句）＋"你的任务"卡（约束逐条）
③ 知识预习：术语翻卡（点击翻转）＋判定标准速查表
④ 六步闯关：按课标六步各设一关，关内 1-3 个交互（选择/拖拽/填空/配置），
   错误即时反馈并引规范条文；通关累积星
⑤ 仿真实训：核心决策点模拟器——"学生做决策→系统给后果→复盘"
⑥ 检测：10 题（单选/判断/排序），即时解析，≥80% 过关
⑦ 成就与去向：徽章＋交付物自检清单＋下一情境入口
```

### 仿真实训的设计判据
- 先问：这个情境学生**必须作出的判断**是什么？围绕 1 个核心决策点（至多 2 个）搭仿真；没有决策点的情境做步骤闯关即可，**不许为仿真而仿真**
- 决策→后果必须有真实代价：错了要能看到"这批货被客户退回""Kappa 不达标发布后被撤回"这类后果链，不是一句"回答错误"
- 各情境推荐核心决策点：

| 情境 | 核心决策点 | 仿真形态 |
|---|---|---|
| LF1-Q1 采集 | 授权边界与抽样方案 | 参数配置模拟器（选模态/场景→配参数→系统校验授权与完整性） |
| LF1-Q2 标注 | "遮挡 30% 算不算目标" | 标注比对模拟器（打标→与标准答案算一致率） |
| LF1-Q3 规则 | 口径缺失时如何裁定 | 争议样本裁定模拟（边界情形→选判定→看依据与对 mAP 影响） |
| LF2-Q1 清洗 | 四类问题的处置规则匹配 | 清洗规则配置游戏（识别问题→选处置→看副本与变更日志） |
| LF2-Q2 根因 | 先记现象还是先调日志 | 排障闯关（现象→分段比对→定位断点，五层排除法） |
| LF2-Q3 脱敏 | 照单标级＋脱敏策略匹配 | 分级脱敏配置模拟（字段→级别→策略→抽查） |
| LF3-Q1 数据集 | 三集划分与泄漏检查 | 数据集构建模拟（采样/划分/查泄漏/出数据卡） |
| LF3-Q2 训练评测 | 不达标时归因 | 训练监控仪表盘（看曲线→四类归因→A/B 验证） |
| LF4-Q1 部署 | 切流量前双人确认 | 部署联调闯关（打包→联调→压测→灰度） |
| LF4-Q2 漂移 | 漂移了先回滚还是先排查 | 漂移监测模拟（判类型→二级审批回滚→复盘） |
| LF4-Q3 质量门 | 交期紧压不压质检比例 | 排产＋质量门配置模拟（人天测算→门限→试运行偏差） |

### 游戏化机制（硬规则）
- 关卡制＋星数；连错 2 次给提示（引条文，不直接给答案）
- **D 类红线全部做成机制**：触发即"炸号"（本关清零重来）并显式引用红线原文——红线不是提示文字
- 达标线 **80%**（与课标一致），不过关锁定重学（可跳过但记录）
- 进度存 `localStorage`，刷新不丢

## 三、工程红线（违反即无法交付）

1. **单文件、零外部请求**：不引 CDN/字体/图片 URL；grep `src="http`、`@import`、`fetch(` 必须为空（`fetch` 仅许用于不存在的场景——干脆不许）
2. 键盘可达：所有交互 Tab/Enter 可操作
3. ≤900px 单栏适配；`@media print` 隐藏控件、显示答案
4. 数据一律"教学样例"，涉个人信息场景用合成样例并显式声明
5. 不用框架、不用构建；JS 全内联在 `</body>` 前
6. 文件命名：`{LF}_Q{n}_{情境名}_学生互动学习模块_正式版.html`

## 四、教师授课包规格（零 JS）

- GitBook 风：左侧固定目录锚点＋右侧正文＋顶部版本条；内联 CSS；打印友好
- 必备块：情境信息条｜六步×四层网格表（A领跑/B主力/C跟进/D兜底，时间分配按六步学时）｜任务工单八栏｜引导文六问｜检查表 8 项｜Rubric 评分表（四维四档）｜错误案例卡 3 张｜安全提示卡（D 类红线）｜教师备课备注（高频错判 Top3、答疑口径"只指条文不判标签"）
- **内容与课标逐字一致，不改数据**；文件名：`{LF}_Q{n}_{情境名}_教师授课包_正式版.html`

## 五、交付前自检

- [ ] 七段齐全；六步关卡与课标六步一一对应，学时一致
- [ ] 核心决策点仿真可操作，错误后果链完整
- [ ] D 类红线全部机制化（逐条对课标红线数）
- [ ] 检测 10 题、达标线 80%、解析含依据
- [ ] 零外部请求、键盘可达、移动端可用、打印友好
- [ ] 与配套教师包数据一致（六步/原子/红线/交付物）

## 六、批量生产时的纪律

1. **先做金标准再铺开**：第一个情境的两件套由主理人＋贺游学共同打磨定版，后续照此复制，**不允许每个情境自创结构**
2. 一个子代理一次只做一个情境的两件套，**不贪多**——贪多的结果是没有一件能交
3. 每个情境产出后跑一遍自检清单，不过自检不交付
