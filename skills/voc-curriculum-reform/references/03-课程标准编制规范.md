# 03 课程标准编制规范（11 章正式版）

> 课程标准是教学的"宪法"。一份合格的课标，换一个老师来上，教的东西、考的标准应该基本一致。

---

## 一、11 章结构总览

| 章 | 标题 | 一句话作用 | 缺失后果 |
|:---:|---|---|---|
| ① | 课程基本信息 | 谁、在哪、多少学时 | 排课无依据 |
| ② | 课程性质与设计思路 | 为什么开、怎么来的 | 说不清 BAG 转化路径 |
| ③ | 国标核心课程与学习领域对应分析 | 国标覆盖了没有 | 评审直接退回 |
| ④ | 课程目标（PGSD-KSA） | 学完能干什么 | 目标不可测 |
| ⑤ | 工作与学习内容五要素 | 学的内容长什么样 | 内容与岗位脱节 |
| ⑥ | 学习情境划分 | 分几个情境、怎么走六步 | 无法上课 |
| ⑦ | 教学实施建议 | 怎么教、AI 怎么用 | 教法随机 |
| ⑧ | 考核评价方案 | 怎么打分、什么算不过 | 评价靠印象 |
| ⑨ | 教学资源与条件 | 要什么设备人 | 开了课上不了 |
| ⑩ | 安全与伦理红线 | 什么绝对不能做 | 出事故无依据 |
| 附录 | A 规范清单 / B 交付物模板 / C AI 清单 / D 评分阈值 | 可直接拿去用的表 | 教师重复造轮子 |

## 二、逐章写作要求

### ① 课程基本信息
表格必备字段：课程名称、课程代码、适用专业、开设学期、总学时/学分（理论/实践分列）、先修课程、后续课程、考核方式、授课场所、班级规模、编制人与审核人、版本号与日期。

**硬要求**：学时学分必须与 Table5 完全一致；版本号写在页首，每次修订升号并保留修订记录。

### ② 课程性质与设计思路
- **②.1 课程性质（学习领域定位）**：说明本课对应哪个工作领域、承载哪几项典型任务、能力等级区间（如 L1→L2）、在专业课程链中的位置。
- **②.2 设计思路——BAG→学习领域转化路径**：写四条设计原则，句式固定：
  1. **工作过程导向（同一参照 6 步）**：N 个情境共用同一六步闭环，载体复杂度螺旋上升。
  2. **能力递进（Dreyfus L?→L?）**：说明从什么水平到什么水平，理论/实践学时比，分层教学安排。
  3. **国标底线强约束**：三要素逐条映射，差异内容由谁补强，杜绝"只讲概念不上真机"。
  4. **AI 融合三层梯度（禁用→陪同→独立）**：高危操作永久禁用 AI 自动执行，AI 生成内容必须人工复核签字。
- **②.3 与先修/后续 LF 与专基课的衔接关系**：用表列出"先修课提供什么基础 → 本课不重复讲什么 → 本课输出什么给后续课"。

**最常见的返工**：只写"本课程是专业核心课"，没写"不重复讲什么"。评审最爱问的就是"这个内容前面课讲过了，你为什么还讲"。

### ③ 国标核心课程与学习领域对应分析
- **③.1 本 LF 承载的国标核心课程定位**：列出国标课程名（与校本名对照）。
- **③.2 三要素覆盖映射**：知识/技能/素质三张子表，逐条 ✅/⚠，⚠ 注明补强路径。
- **③.3 承载课程学时分布闭环**：国标课程学时 = 本 LF 分配学时 + 其他课程承担学时，做加法验证。
- **③.4 差异分析**：校本增强项（企业新技术）、弱化项（国标有但岗位不用）各列 2-3 条，写理由。
- **③.5 覆盖度结论**：一句话结论 + 数据（如"三要素 100% 覆盖，其中 2 项由 LF4 补强"）。

### ④ 课程目标
- **④.1 总体目标**：一段话，说清"能独立完成什么工作、达到什么质量、具备什么职业行为"。
- **④.2 PGSD-KSA 分解目标**：表格，列为 `编号 | 维度 | 目标（行为动词开头）| 绑定原子 ID | 评价方式`。每条目标必须绑一个原子，反之亦然。
- **④.3 分层培养目标（ABCD 学情适配）**：

| 层级 | 比例 | 目标定位 | 出口 |
|:---:|:---:|---|---|
| A 领跑型（组长/架构师） | 20% | 独立完成全流程方案设计+优化+可指导 B/C 层+AI 陪同层独立使用 | 1+X 中级/高级、企业实习推荐 |
| B 主力型（工程师） | 50% | 独立完成核心模块配置/实操/排故+AI 陪同层熟练使用 | 1+X 中级、核心岗位 |
| C 跟进型（实施员） | 20% | 在 B 层帮扶下完成基础操作+红线零违反+6S 合格 | 助理岗/运维员 |
| D 兜底型（实习员） | 10% | B 层以上陪同下完成辅助任务，高危操作禁独立 | 认知合格、带教岗位 |

**行为动词替换表**

| 禁用（不可测） | 换成（可测） |
|---|---|
| 了解、熟悉、知道 | 能说明…的原理 / 能识别… / 能复述…并对照实物指出 |
| 掌握、学会 | 能独立完成…（含量化门槛）/ 能在…分钟内完成 |
| 具备…能力 | 能输出…文档 / 能定位…故障 / 能在信息不全时判断… |
| 培养…意识 | 每次操作前执行…并签字 / 发现…立即停止并上报 |

### ⑤ 工作与学习内容五要素
| 要素 | 写什么 | 示例 |
|---|---|---|
| 工作对象 | 处理的是什么 | 工业现场传感器信号、PLC 数据点、网关配置参数 |
| 工具、材料与资料 | 用什么干 | 万用表、网关配置工具、协议分析软件、作业指导书、点位清单 |
| 工作方法 | 按什么方法干 | 六步法、逐段隔离法、先备份后变更、AI 辅助生成+人工复核 |
| 劳动组织方式 | 几个人怎么配合 | 独立操作+自检；双人确认；指导人逐项签字 |
| 工作要求与质量标准 | 干到什么程度算合格 | 配置一次性成功率 ≥80%、数据完整率 ≥99%、文档齐全签字 |

### ⑥ 学习情境划分（课标的核心）
- **⑥.1 总览表**：`情境编号 | 情境名称 | 学时/学分 | 学期 | 能力等级 | 对应任务 | 交付物`。
- **⑥.2 六步学时合计校验**：每个情境六步学时之和 = 情境学时；全部情境之和 = 课程总学时。
- **⑥.3 各情境详表**（一情境一节），每节必须含：
  1. 情境描述（一句场景化的话 + 真实载体，如"某产线 3 台设备协议不通"）
  2. 六步流程表：`步骤 | 教师活动 | 学生活动 | 学时 | 产出`
  3. 原子能力绑定（编号列表）
  4. D 类硬约束（本情境专属安全红线）
  5. 交付物清单（对应附录 B 模板）
  6. 评价要点（对应第⑧章 Rubric 维度）

**情境命名规范**：动宾结构 + 载体，如"传感器认知与接线""多设备联调排故"；不要用"项目一""模块二"。

### ⑦ 教学实施建议
- **⑦.1 六步行动导向实施要点**：逐步骤写"教师做什么、学生做什么、常见失败点"。**决策步必须有评审环节**（学生讲方案、教师/同伴质疑、签字确认后才允许实施）。
- **⑦.2 教师角色矩阵**：`阶段 | 讲授者 | 教练 | 评审者 | 安全监督`，标出每步的主角色。
- **⑦.3 AI 工具三层梯度**（详见 `04-教学实施与教案设计.md`）：禁用层 / 陪同层 / 独立层，逐层写适用情境与审批要求。
- **⑦.4 教学组织建议**：分组规模（4-5 人）、工位轮换、双师配置、企业导师介入点。

### ⑧ 考核评价方案
- **⑧.1 总体权重**：过程性 x% + 终结性 y%（建议 60/40 或 70/30），并说明过程性证据种类。
- **⑧.2 Rubric 四维评分**：专业 40 / 方法 25 / 社会 20 / 发展 15，各维 4/3/2/1 四档描述（见 `05-评价与质量红线.md`）。
- **⑧.3 COMET 能力达成阈值**：K1-K4 各层达标比例。
- **⑧.4 一票否决项**：红线违反、交付物缺失、代做抄袭。

### ⑨ 教学资源与条件
硬件（工位数、设备型号与数量、生均台套）、软件（授权、版本、云平台账号）、师资（双师比例、企业导师）、教材与参考（含活页教材）、数字化资源（微课、仿真、云实训）、活页工作页与模板清单。

**硬要求**：写清"几人一台/套"，否则无法核算开课成本；云实训要写"学生独立账号、随时可用"。

### ⑩ 安全与伦理红线（D 类硬约束）
- **⑩.1 情境化红线总览**：表格，`情境 | 红线条目 | 后果 | 检查方式`。
- **⑩.2 每情境细则**：至少覆盖电气安全（带电接线、接地、LOTO）、设备安全（超压、超温、误操作）、数据安全（连接生产环境、数据外传）、学术诚信（AI 代写、伪造数据）。
- **⑩.3 伦理与安全教育实施**：入学第一课、每次课前三分钟、违规处理流程。

**写法要求**：红线必须是"能被检查的动作"，不是"要注意安全"。例："未执行 LOTO 即开始接线 → 本情境 0 分 + 重做 + 安全培训"。

## 三、附录四件套

| 附录 | 内容 | 用途 |
|---|---|---|
| A | 本课强制执行规范与标准清单（国标号、行业标准、企业 SOP 编号） | 评审查依据 |
| B | 交付物模板（任务签收单、LOTO 记录卡、BOM 清单、配置参数表、验证报告、验收包、评分表…） | 教师直接印发 |
| C | AI 工具三层梯度清单（逐工具、逐场景） | 课堂管理依据 |
| D | Rubric 四档阈值 + COMET 四档阈值 + 自检标准 | 评分一致性 |

## 四、质量标准（评审专家会看的 8 个点）

1. 学时学分与 Table5 一字不差。
2. 三要素覆盖有 ✅/⚠，⚠ 有补强路径。
3. 每个情境六步齐全，六步学时能加平。
4. 每条目标有原子编号与评价方式。
5. Rubric 四维齐全，档位描述可区分。
6. 一票否决项可执行（有检查方式、有后果）。
7. 设备台套数写清，能算出开课成本。
8. 版本号、修订记录、编制审核人齐全。

## 五、常见退回原因（提前避开）

| 退回意见 | 根因 | 修法 |
|---|---|---|
| "目标不可测" | 用了"了解/掌握/具备" | 按行为动词表逐条改写 |
| "与国标不符" | 没做三要素映射 | 补第③章，做 ✅/⚠ 表 |
| "学时对不上" | 模块改了没回填 | 建学时台账，三处对齐 |
| "情境不是工作过程" | 只写了操作步骤 | 补资讯、计划、决策、评价四步 |
| "评价无依据" | 只有期末卷 | 补过程性证据链与 Rubric |
| "纸上课程" | 无真机、无工位、无数据源 | 补设备清单与实训条件，或调整任务 |
| "AI 使用无边界" | 没写禁用层 | 补 AI 三层梯度清单 |
